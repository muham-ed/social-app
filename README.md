## 📖 نبذة عن المشروع
**Social App** منصة تواصل اجتماعي متكاملة تجمع بين أفضل ما في التطبيقات العالمية:
> 🎬 **فيديوهات قصيرة** بنمط TikTok • 🎙️ **غرف صوتية مباشرة** بنمط Clubhouse • 📍 **تعارف جغرافي** • 💬 **مراسلة فورية** • 🛡️ **إشراف وحماية (UGC)**

---

## ✨ الميزات الرئيسية
*   🎬 **Short Video Feed:** تصفح فيديوهات عمودية مع تفاعلات حية.
*   🎙️ **Audio/Video Rooms:** بث مباشر عبر Agora SDK بأقل زمن انتقال.
*   📍 **Location Discovery:** اكتشاف المستخدمين القريبين مع حماية الخصوصية.
*   💬 **Real-time Chat:** نظام دردشة حي مع Typing Indicators عبر WebSockets.
*   👑 **Admin Dashboard:** لوحة تحكم ويب شاملة لإدارة المنصة بالكامل.

---

## 🏗️ المعمارية التقنية
المشروع مبني باستخدام **Clean Architecture** و **BLoC Pattern** لضمان استقلالية الكود وسهولة الاختبار.

---

## 🛠️ التقنيات المستخدمة
*   **Frontend:** Flutter, Dart, BLoC, Dio, GoRouter.
*   **Backend:** Node.js, Express, MongoDB, Socket.io.
*   **Real-time:** Agora RTC, Redis.
*   **Infra:** Docker, GitHub Actions.

---

## 🚀 البدء السريع
1. `git clone https://github.com/muham-ed/social-app.git`
2. `docker-compose up -d`
3. `make install`
4. `make dev`
